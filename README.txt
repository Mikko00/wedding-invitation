MIKKO & MARIA ELLAINE — WEDDING WEBSITE

FILES
- index.html: main website
- styles.css: blush pink, sage green, ivory and gold styling
- script.js: animations, countdown, gallery viewer, navigation and RSVP helper
- assets/: the three supplied invitation images

PREVIEW
Open index.html in a modern browser. For a local web server, run:
  python -m http.server 8000
Then open http://localhost:8000

PUBLISHING
Upload the complete folder contents to any static web host (GitHub Pages, Netlify,
Cloudflare Pages, or your web hosting). Keep the assets folder alongside index.html.

IMPORTANT
The RSVP form currently prepares a message and does not save responses online.
The email draft uses a blank recipient because no RSVP email address was supplied.
Update the mailto recipient in script.js before publishing if you want email RSVPs.
The venue/date/time are based on the invitation artwork.
